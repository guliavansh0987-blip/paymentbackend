ZapPay Backend — Environment Variables Reference
=================================================
This file lists every environment variable the backend reads, with a hint
for what to put there. NO REAL VALUES are included — fill each one in on
your actual hosting platform's Environment Variables settings (e.g. Vercel
→ Project → Settings → Environment Variables), never commit real secrets
into this file or into git.

Rename this file to `.env` (with the values filled in) for local
development only. On Vercel/production, set these directly in the
dashboard instead of uploading a .env file.


─── FIREBASE (required) ─────────────────────────────────────────────────
Get these from Firebase Console → Project Settings → General (the web app
config block) AND → Service Accounts → Generate new private key (for the
Admin SDK credentials).

FIREBASE_API_KEY=              # Project Settings → General → Web API Key
FIREBASE_AUTH_DOMAIN=          # usually YOUR_PROJECT_ID.firebaseapp.com
FIREBASE_DATABASE_URL=         # Realtime Database → your instance URL, looks like https://YOUR_PROJECT_ID-default-rtdb.firebaseio.com
FIREBASE_PROJECT_ID=           # your Firebase project ID (also used as the Admin SDK project ID)
FIREBASE_STORAGE_BUCKET=       # usually YOUR_PROJECT_ID.appspot.com
FIREBASE_MESSAGING_SENDER_ID=  # Project Settings → Cloud Messaging → Sender ID
FIREBASE_APP_ID=               # Project Settings → General → App ID (web app)

FIREBASE_CLIENT_EMAIL=         # From the downloaded service-account JSON: the "client_email" field
FIREBASE_PRIVATE_KEY=          # From the same service-account JSON: the "private_key" field — keep the \n
                                # line breaks escaped as literal \n if pasting into a single-line env var
                                # field (most hosts, including Vercel, handle this automatically if you
                                # paste the whole key including -----BEGIN PRIVATE KEY-----/-----END-----)

FCM_VAPID_KEY=                 # OPTIONAL — Project Settings → Cloud Messaging → Web configuration →
                                # Generate key pair. Only needed for browser push notifications; the
                                # rest of the app works fine without it.


─── AUTH / SECURITY (required) ──────────────────────────────────────────
JWT_SECRET=                    # any long random string — used to sign login tokens. Generate one with
                                # `openssl rand -hex 32` or similar. NEVER reuse a value you've seen in
                                # a tutorial or example.
JWT_EXPIRES_IN=                # OPTIONAL — how long a login session lasts, e.g. 30d (defaults to 30d if unset)

ADMIN_SECRET=                  # a secret passphrase required to create the FIRST admin account via
                                # POST /api/auth/create-admin. Set this to something only you know, use
                                # it once to bootstrap your own admin account, then treat it as compromised
                                # and consider rotating it.

ENCRYPTION_KEY=                # MUST be exactly 32 characters. Used to encrypt sensitive stored data
                                # (e.g. connected cashier credentials). Generate with
                                # `openssl rand -hex 16` (gives 32 hex characters). The code has a
                                # hardcoded fallback if this is unset — DO NOT rely on that fallback in
                                # production, it is not secret.


─── URLS (required) ──────────────────────────────────────────────────────
FRONTEND_URL=                  # your main panel's live URL, e.g. https://panel.yourdomain.com
                                # Can be a COMMA-SEPARATED list if you have multiple live frontend
                                # origins (used for CORS allowlisting) — code that needs a single URL
                                # (redirects, push links) always takes just the first entry in the list.

STORE_URL=                     # OPTIONAL — root marketing/store domain if different from FRONTEND_URL,
                                # e.g. https://yourdomain.com (defaults to FRONTEND_URL's first entry if unset)

WEBHOOK_URL=                   # OPTIONAL — base URL used when building webhook callback URLs your own
                                # backend sends out

TEST_GATEWAY_URL=              # OPTIONAL — base URL for the Test Mode / gateway simulator page (test.html)


─── ZAP UPI GATEWAY (required — this is YOUR upstream UPI processor) ────
ZAP_API_URL=                   # OPTIONAL — defaults to https://pay.zapupi.com/api if unset. Only change
                                # this if ZapUPI gives you a different API base URL.
ZAP_KEY=                       # your ZapUPI merchant API key — get this from your ZapUPI dashboard


─── SMS / MANUAL VERIFICATION WEBHOOK ───────────────────────────────────
SMS_WEBHOOK_SECRET=            # a secret token your SMS-forwarding source (phone app / gateway) must
                                # send to authenticate requests to your SMS webhook endpoint. Make this
                                # a long random string, same idea as JWT_SECRET.


─── EMAIL / SMTP (optional — only needed if you send transactional emails) ─
SMTP_HOST=                     # e.g. your domain's mail server, from your host's Email Accounts →
                                # Connect Devices → SSL/TLS settings
SMTP_PORT=                     # 465 for SSL, or 587 for STARTTLS
SMTP_SECURE=                   # 'true' if using port 465, 'false' if using port 587
SMTP_USER=                     # the mailbox address, e.g. help@yourdomain.com
SMTP_PASS=                     # that mailbox's password — treat as a secret, never commit
SMTP_FROM_NAME=                # OPTIONAL — display name for outgoing mail, defaults to 'ZapPay Gateway'


─── AI AGENT MODELS (optional — only needed if the Agent feature is used) ─
NVIDIA_MODEL_ZPPX=             # OPTIONAL — model identifier for the "ZPP-X" agent (defaults to
                                # deepseek-ai/deepseek-v4-pro if unset)
NVIDIA_FALLBACK_MODEL_ZPPX=    # OPTIONAL — fallback model if the primary is unavailable (defaults to
                                # deepseek-ai/deepseek-v4-flash if unset)
NVIDIA_MODEL_ZPPY=             # OPTIONAL — model identifier for the "ZPP-Y" agent (defaults to
                                # z-ai/glm-5.2 if unset)
NVIDIA_FALLBACK_MODEL_ZPPY=    # OPTIONAL — fallback model for ZPP-Y (no default; leave unset if you
                                # don't want a fallback)
                                # NOTE: these model calls need their own API key/credentials wired into
                                # whatever client agentService.js uses — check that file for what
                                # additional provider credentials it expects beyond these model names.


─── MISC ─────────────────────────────────────────────────────────────────
SITE_NAME=                     # OPTIONAL — display name shown in the app/emails, defaults to 'ZapPay'
NODE_ENV=                      # 'production' on your live deployment, 'development' locally
PORT=                          # OPTIONAL — port the server listens on locally (Vercel ignores this
                                # and manages it automatically; only relevant if you self-host)


─── NOT AN ENV VAR — set in Vercel Project Settings instead ─────────────
Google Sign-In / any OAuth client IDs are configured on the FIREBASE
CONSOLE side (Authentication → Sign-in method), not as backend env vars —
nothing to add here for that.
